# GitHub uploads

For uploads to this repository:

- Keep `index.html` and all published site files at the repository root.
- Set the commit author to `sanraphically <sanraphically@proton.me>`.
- Do not add `Co-authored-by` trailers or other co-authors.
- Commit only work authored for this repository under the `sanraphically` identity.

Set the repository-local author before committing:

```sh
git config user.name "sanraphically"
git config user.email "sanraphically@proton.me"
```
